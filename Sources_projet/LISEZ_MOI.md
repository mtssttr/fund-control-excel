# Données du projet

propre : registre complet, règlements normaux, cours complets.
investigation : cinq altérations des entrées internes/cours et un règlement retardé.
extension_20260928 : jeu propre prolongé avec les clôtures fictives du 28/09 pour tester un 11e jour.
Toutes les données de cours et de fonds sont fictives. Les titres réels servent seulement de noms de référence.
Les CSV sont UTF-8, séparateur point-virgule, dates ISO, décimales avec point.
Les neuf fichiers .pq contiennent le code des requêtes intégrées. Aucun module VBA n’est requis.
Ne remplacer aucune donnée manquante par un zéro pour obtenir artificiellement un rapprochement.
